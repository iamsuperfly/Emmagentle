# Emma Gentle UI

Use this skill when restyling [Emmagentle](https://github.com/iamsuperfly/Emmagentle).

## Design read

Trade supplier catalogue. Trust-first. Dense stock. Almost no motion.

## Rules

- Do not fuse the logo with a portrait or product photo
- Do not use italic display serif in the hero
- Do not use Inter as the brand type unless the codebase already requires it
- Do not ship purple-blue gradient buttons
- Do not stack identical icon tiles or “01 Discover / 02 Design / 03 Deliver”
- Do not write placeholder copy such as “bringing your ideas to life”
- Keep WhatsApp and hours obvious
- Admin stays operational, not pretty
- Change CSS, layout classes, type, spacing, imagery treatment, and microcopy only
