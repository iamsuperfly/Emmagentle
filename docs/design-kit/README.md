# Emma Gentle design kit

Companion notes for the Emmagentle catalogue restyle.

This kit is documentation, not an application. The live product stays in [iamsuperfly/Emmagentle](https://github.com/iamsuperfly/Emmagentle).

A standalone public repo is also published at [iamsuperfly/emma-gentle-design-kit](https://github.com/iamsuperfly/emma-gentle-design-kit). The same files live here so the visual-pass PR is self-contained.

## Upstream skills

- Taste Skill (frontend anti-slop): https://github.com/Leonxlnx/taste-skill
- Impeccable: https://github.com/pbakaus/impeccable
- Emil Kowalski skills: https://github.com/emilkowalski/skill
- DESIGN.md spec: https://github.com/google-labs-code/design.md
- Playwright (visual checks only, not forked into the org): https://github.com/microsoft/playwright
